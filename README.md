# GLOBUSSOFT-tasks-

Task 1 – Amazon Laptop Scraper

Developed a Python-based web scraper to extract laptop product details from Amazon India, including title, image URL, rating, price, and ad/organic status. The scraped data is stored in a timestamped CSV file for analysis and reporting.

Task 2 – Face Authentication / Drone Detection

Built a FastAPI-based AI service for either face verification or drone detection using pre-trained deep learning models. The API performs image inference and returns detection results such as similarity scores, bounding boxes, confidence levels, and object counts.
